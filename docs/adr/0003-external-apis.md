# ADR 0002: 外部API選定

- Status: Accepted
- Date: 2026-04-03
- Last-validated: 2026-04-03

## Context

天気・潮汐・ルート計算に外部APIが必要。ランニングコスト ¥0 の制約のもとで選定する。

## Decision

### 天気・海況: Open-Meteo

**却下した選択肢:**
- Storm Glass: 無料枠10req/日では複数ポイント×7日分を取得できない。有料は€19/月〜。
- OpenWeatherMap: 無料枠はあるが海況（波・うねり）のデータが弱い。

**採用理由:**
- 完全無料、APIキー不要、登録不要
- Weather API + Marine APIで天気・風・波・うねりをカバー
- 非商用利用はCC BY 4.0
- 1日10,000リクエストまで無料
- 日本はDWD ICONモデルでカバー

### 潮汐: tide736.net

**却下した選択肢:**
- WorldTides: クレジット制で従量課金。
- TideCheck: 無料50req/日。メインには心許ないがバックアップとして保持。

**採用理由:**
- 日本沿岸736港をカバー、日本の釣り場に最適
- 無料で利用可能
- JSON APIでデータ取得可能

**リスク対策:**
- サポートなし、予告なく終了の可能性
- バックアップ: TideCheck（50req/日無料）
- 最終手段: 海上保安庁の調和定数表から自前計算

### 距離計算: Haversine直線距離（変更済み）

> ⚠️ 当初OSRMを採用予定だったが、サブ機のRAM・ディスク要件を満たせないためHaversineに変更。
> 詳細は ADR 0005 を参照。

**採用理由:**
- 追加インフラ不要（appコンテナのみで完結）
- 実装がシンプルで依存ゼロ
- 沿岸の釣り場は直線距離でも実用上の誤差が小さい

### 魚種データ: 静的DB（JSON）

**却下した選択肢:**
- Claude API: 柔軟だが従量課金。

**採用理由:**
- ランニングコスト ¥0
- 地域×月×魚種×釣り方×餌をJSONで管理
- 初期データはClaude（チャット）で一括生成し、ファイルに落とし込む
- 将来的にClaude APIでの動的提案を検討

## Consequences

- tide736.net依存のリスクあり。バックアップ手段を初期実装に含める
- Open-Meteoの日本沿岸データ精度は実データで検証が必要
- 距離計算はHaversine直線距離（OSRM不使用）。山間部・半島先端は誤差が出る可能性あり
- 魚種データは手動更新。精度向上には実釣果のフィードバックが必要
