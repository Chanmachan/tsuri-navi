# iOS App Spec: tsuri-navi

## 概要

既存の Next.js バックエンド（サブ機サーバー）をそのまま使用し、
SwiftUI でネイティブ iOS クライアントを構築する。

- スコア計算・データ収集はバックエンドが引き続き担当
- iOS アプリは API を叩く純粋なクライアント
- プッシュ通知はローカル通知（APNs 不使用）
- 配布対象：自分の iPhone のみ（Xcode 無料プロビジョニング）

---

## ゴール（PWA との差分）

| 項目 | PWA | iOS ネイティブ |
|---|---|---|
| プッシュ通知 | Web Push（要ホーム画面追加） | ローカル通知（起動時に自動スケジュール） |
| グラフ | Recharts | Swift Charts |
| 地図 | Leaflet | MapKit |
| インストール | ホーム画面追加 | Xcode 経由でサイドロード |
| オフライン | ServiceWorker キャッシュあり | なし |
| 操作感 | Web | ネイティブ（スワイプ、haptic等） |

---

## 画面構成

### タブ構成
```text
[ホーム] [検索] [マップ] [設定]
```

### ホーム画面
- 登録釣り場の一覧（今日のスコア ◎○△×）
- ベストタイム表示（例:「05:00 がベスト」）
- 週間カレンダー（横スクロール、7日分のスコア色分け）
- お気に入り★マーク
- タップで釣り場詳細へ遷移

### 釣り場詳細画面
- スコア大表示 + 判定内訳（潮回り・風速・波高・天気・マズメ等）
- 時間帯別スコアバー（ベストタイムハイライト）
- タイドグラフ（Swift Charts、日の出・日の入りライン）
- 天気・風・波の時間帯別テーブル
- 今の時期に狙える魚種と餌
- 日付切り替え（週間カレンダーで日付選択）

### 検索画面
- 日付セレクト（今日〜7日後）
- 距離スライダー（10〜500km）
- 結果リスト（スコア順）
- MapKit マップ（スコア色分けアノテーション）

### マップ画面
- 全登録釣り場を MapKit で表示
- スコア色のアノテーション（◎緑 ○青 △黄 ×赤）
- タップで釣り場詳細へ遷移
- 長押しで新規釣り場追加

### 設定画面
- サーバー URL 入力（例: `http://192.168.1.x:3002`）
- 自宅位置（緯度・経度）
  - 現在地から取得ボタン
- ローカル通知 ON/OFF
- スコア重みカスタマイズ（将来対応）

## ローカル通知

Apple Developer Program なし → APNs 不使用。

### 方針
- アプリ起動時に今後7日分のスコアをチェック
- スコア ◎（80点以上）の釣り場・日付があれば通知をスケジュール
- 通知タイミング：条件の良い日の前日 18:00
- 例:「明日、久ノ浜漁港が好条件です（◎ 87点）」

### 制約
- アプリを開かないと通知がスケジュールされない
- サーバーがダウンしていると更新されない

---

## サーバー接続

- サーバー URL はアプリ内設定で管理（UserDefaults）
- 自宅 LAN 内では `http://192.168.x.x:3000` 形式
- 外出先では VPN or 自宅サーバーのポート開放が必要（設定画面で URL 変更）

---

## プリセット釣り場

既存バックエンドの DB にすでに登録済み。iOS アプリ側での管理は不要。
