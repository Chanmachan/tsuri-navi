# Spec: tsuri-navi — 海釣り条件ナビゲーター

## プロジェクト概要

天気・潮汐・波・風などの海況データを総合的に判断し、**「いつ・どこで・何を狙うか」を結論ファーストで提示する**海釣り特化の個人向けナビアプリ。
サブ機サーバー上でバックエンドを常駐稼働させ、定期的にデータ取得・スコア計算・プッシュ通知を行う。

> 開発動機：釣り場に到着してから「今日ダメじゃん」と気づくのを防ぎたい。
> タイドグラフBIのような既存アプリはデータはあるが「結局いつ行けばいいの？」が分かりづらい。

---

## ゴール

1. 登録した釣り場の「釣りやすさスコア」を自動算出し、◎○△× で直感的に判定する
2. 時間帯ごとのスコアを表示し、その日のベストタイムを一目で分かるようにする
3. 週間カレンダーで「良い日」が事前に把握でき、釣行計画を立てやすくする
4. 自宅からの距離を指定し、条件の良い釣り場をおすすめ順で検索できる
5. 好条件の日はプッシュ通知で事前に知らせる
6. ランニングコスト ¥0 で運用する（電気代・ネット代除く）

---

## スコープ（MVP）

### In scope
- 海釣りのみ（堤防・漁港・磯・サーフ）
- データ収集：Open-Meteo（天気・海況）、tide736.net（潮汐）
- 釣りやすさスコア：潮回り・風速・波高・天気・マズメ時間帯・気圧・月齢を重み付けして100点満点で算出
- 時間帯別スコア：1時間ごとにスコアを計算し、ベストタイムをハイライト
- 週間カレンダー：7日間のスコア一覧（◎○△× の色分け）
- タイドグラフ：潮位変化のグラフ表示（満潮・干潮時刻、潮回り、日の出・日の入り）
- 天気・海況表示：風速・風向、波高・うねり、気温、降水量、気圧
- 釣り場管理：複数ポイントの登録・お気に入り管理、地図上での自由追加
- 距離ベース検索：自宅からの直線距離（km）を指定し、範囲内の好条件ポイントをスコア順で表示
- 魚種提案：地域×季節に応じた狙える魚種・釣り方・餌を表示（静的DB）
- プッシュ通知：登録ポイントの好条件を2日前に通知
- プリセット釣り場：いわき市周辺、宮城、四国の主要ポイントを初期搭載
- インフラ：Docker Composeでサブ機サーバー上にバックエンド常駐

### Out of scope（MVP以降）
- 釣果記録・日記機能
- 他ユーザーとの共有・SNS的機能
- 川・湖の淡水釣り
- リアルタイム混雑情報
- AI（Claude API）による動的な魚種・釣り方提案
- Google Maps APIによる高精度ルート計算

## コア機能

### 1. 釣りやすさスコア（最重要）

潮回り・天気・風速・波高・マズメ時間帯・気圧・月齢を重み付けして100点満点で算出。

| 要素 | 配点 | 良い条件 | 悪い条件 |
|---|---|---|---|
| 潮回り | 20点 | 大潮・中潮 | 若潮・長潮 |
| 潮の動き（時間帯） | 15点 | 満潮・干潮の前後1-2時間 | 潮止まり |
| 天気 | 15点 | 曇り・小雨 | 大雨・雷 |
| 風速 | 15点 | 微風（2-5m/s） | 強風（10m/s+） |
| 波高 | 15点 | 0.5-1.5m | 2.5m+ |
| 時間帯（朝夕マズメ） | 10点 | 日の出前後・日没前後 | 真昼間 |
| 気圧変化 | 5点 | 高気圧安定 | 急激な気圧低下 |
| 月齢 | 5点 | 新月・満月付近 | 半月 |

| スコア | 判定 | 表示 |
|---|---|---|
| 80-100 | 絶好の釣り日和 | ◎（緑） |
| 60-79 | まずまず良い | ○（青） |
| 40-59 | 条件はいまいち | △（黄） |
| 0-39 | 行かないほうがいい | ×（赤） |

### 2. 天気・海況情報
- 気温、天気、風速・風向、降水量、気圧
- 波高、うねり、波の周期
- 7日間予報

### 3. タイドグラフ（潮汐）
- 1日の潮位変化をグラフ表示
- 満潮・干潮の時刻と潮位
- 潮回り（大潮・中潮・小潮・長潮・若潮）
- 日の出・日の入り時刻の表示

### 4. 釣り場管理
- 複数の釣り場を登録・お気に入り管理
- 地図上でポイントを選択・追加（漁港だけでなく岩礁なども自由に）
- プリセット釣り場を初期搭載

### 5. 距離ベースおすすめ検索
- 自宅からの直線距離（km）を指定し、範囲内の釣り場を検索
- 距離は自由に変更可能（10km〜200km+）
- 指定日の条件が良い場所をスコア順で表示

### 6. 魚種×季節×餌の提案
- 地域と時期に応じて狙える魚種を表示
- 各魚種に対して釣り方と餌を提案
- 静的データベース（JSON）で管理

### 7. 週間カレンダー
- 7日間の各日のスコアを一覧表示
- 良い日が一目で分かる（色分け: ◎緑 ○青 △黄 ×赤）

### 8. プッシュ通知
- 登録ポイントの好条件を事前通知
- 例:「今週末、久ノ浜漁港が好条件です（スコア85）」
- 通知タイミング: 2日前（週末前の木曜夕方など）

## 画面構成

### ホーム画面
- 登録ポイント一覧 + 今日のスコア（◎○△×）
- 「今日のベストタイム」を目立つように表示
- 週間カレンダー（横スクロール、7日分のスコア色分け）

### 釣り場詳細画面
- スコア（大きく表示）+ 判定理由の内訳
- 時間帯ごとのスコアバー（ベストタイムハイライト）
- タイドグラフ（日の出・日の入りライン付き）
- 天気・風・波の時間帯別テーブル
- 今の時期に狙える魚種と餌

### 検索画面
- 距離スライダー（直線距離、10km〜200km+）
- 日付選択
- 結果：スコア順の釣り場リスト + 地図表示

### 設定画面
- 自宅位置の設定
- お気に入り釣り場の管理
- 通知ON/OFF・タイミング設定

## コスト方針

| 項目 | コスト |
|---|---|
| Open-Meteo API | 無料（非商用、キー不要） |
| tide736.net API | 無料（サポートなし） |
| Haversine距離計算 | 無料（外部依存なし） |
| Leaflet + OpenStreetMap | 無料 |
| サーバー | サブ機（既存、追加コストなし） |
| **合計ランニングコスト** | **¥0** |

使い勝手を確認した上で、以下の有料サービスを段階的に検討：
- Claude API（魚種のAI動的提案）
- Google Maps Directions API（高精度ルート計算）
- Storm Glass API（天気+潮汐ワンストップ、より高精度）

## リスクと制約

| リスク | 対応方針 |
|---|---|
| tide736.netの突然終了 | TideCheck（50req/日無料）をバックアップ。将来的に調和定数からの自前計算も視野 |
| Open-Meteoの日本沿岸データ精度 | 実データで検証し、精度不足なら有料API（Storm Glass）に切り替え |
| サブ機のダウン・ネットワーク障害 | PWAオフラインキャッシュで直近データは閲覧可能。将来的にクラウド移行も視野 |
| PWAプッシュ通知の制約 | iOS 16.4+必須、ホーム画面追加が前提。ユーザー（自分）に手順を案内 |
| スコア精度 | 実際の釣果と照らし合わせてチューニング。重みは設定画面から調整可能にする |
